## What is comparable

The [2026-09-05 methodology](2026-09-05.md#what-is-comparable) applies here:
idle journal threads differ from Legacy's retained PTYs/CLIs; echo turns measure
core work rather than providers; Bun and compiled-Rust cold starts differ; the
Legacy desktop was already running with terminals. Preserve those boundaries
when comparing the table.

## Not measured

- `claude.turn`: `BOITE_BENCH_CLAUDE` was not 1, so this run used no real account; the recorded live row is from on 2026-09-05
- the legacy desktop app's start time: launching it would put a window on the screen
- throughput on real agents, either side: the echo driver measures the core, and a real multi agent run costs tokens on the user account
