# File checkpoints: shared blobs, root cache and parent checks

Date: 2026-10-15. Machine: LXC `boite` (Ryzen 7 5825U, 8 CPUs capped, nice 10),
Linux, ext4-backed data directory under `/tmp`. Other jobs ran on the machine
at the same time, so single samples vary by up to 50 %.

Command, run three times on `origin/main` (bd566df4, with this branch's bench
file copied in) and three times on the branch, alternating:

```sh
nice -n 10 bun run bench/checkpoint-files.ts
```

The bench snapshots a flat fixture (1000 identical 32 KiB files) and a nested
one (1000 distinct 4 KiB files three folders deep) directly, then drives two
threads on the nested folder through the core's checkpoints, two turns each,
and a third owner of thread 1 as after a restart. Each value is the median of
the three runs; a "warm" value first takes the median of the warm samples of
each run.

| Case | origin/main | branch |
| --- | ---: | ---: |
| Nested snapshot, warm cache | 343 ms | 169 ms |
| Flat snapshot, warm cache | 58 ms | 56 ms |
| Thread 1, first turn in a new folder | 714 ms | 875 ms |
| Thread 1, later turn | 253 ms | 200 ms |
| Thread 2, first turn in the same folder | 608 ms | 276 ms |
| Restart, first turn of thread 1 | 588 ms | 598 ms |
| Blob files on disk after both threads | 2000 (8.19 MB) | 1000 (4.10 MB) |

- Parent checks once per folder per snapshot: the nested warm snapshot takes
  about half the time; the flat one has no parents to check and stays the same.
- Cache per folder: a second thread's first turn reuses the first thread's
  metadata and only links the blobs.
- Shared store: each content is stored once. The first snapshot of a folder
  no thread has saved before now also creates the shared name of each new
  blob (one hard link and one `lstat` per file), about 160 ms more for 1000
  new files. Every later thread in that folder skips that cost and the read.
- After a restart, a cold snapshot of an existing thread replaces the old
  read-back of every existing blob with two `lstat` calls and a link attempt;
  with 4 KiB files the two cost the same.
