## What is comparable

Boite 2's idle threads are journal rows and session IDs, with no CLI process
until execution. Their per-thread working-set estimate is within measurement
noise. Legacy threads retain a PTY, `cmd.exe`, `conhost.exe` and, after an agent
starts, its CLI until the terminal closes.

Echo turns stream from memory without a model or network call. They measure the
scheduler, journal and WebSocket; Legacy's PTY relay has no equivalent. Cold
starts also differ: Bun interprets the TypeScript core and opens SQLite, while
Legacy runs a compiled Rust server. Desktop RSS compares the hidden Boite 2
shell with an already-running Legacy app containing terminals.

## Not measured

- `claude.turn`: `BOITE_BENCH_CLAUDE` was not 1, so this run used no real account; the recorded live row is from on 2026-09-05
- the legacy desktop app's start time: launching it would put a window on the screen
- throughput on real agents, either side: the echo driver measures the core, and a real multi agent run costs tokens on the user account
