---
description: Save the Claude Code login you are on into the pool
allowed-tools: Bash(~/.claude-tools/kebacc-switch:*), Bash(~/.claude-tools/kebacc-switch.exe:*)
---

Run `~/.claude-tools/kebacc-switch`, or `~/.claude-tools/kebacc-switch.exe` on Windows:

```
~/.claude-tools/kebacc-switch add -Provider claude
```

Report the account it saved. If it says you are not logged in, say so and stop.
