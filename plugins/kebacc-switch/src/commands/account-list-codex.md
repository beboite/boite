Run `~/.claude-tools/kebacc-switch`, or `~/.claude-tools/kebacc-switch.exe` on Windows:

```
~/.claude-tools/kebacc-switch list -Provider codex
```

Pass `-Refresh` instead if the user wants fresh numbers from the API rather than the cache.
