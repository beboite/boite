# Code of conduct

boite follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It covers issues, pull requests, reviews, commit messages and all other
repository spaces.

Report unacceptable behavior to the maintainers using GitHub's "Report content"
option on issues, pull requests and comments. Maintainers review every report
and apply the Covenant's enforcement guidelines.
