# Code of conduct

boite follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, reviews, commit messages and every other
space of this repository.

Report unacceptable behavior to the maintainers with the "Report content" option
GitHub shows on every issue, pull request and comment. The maintainers review each
report and apply the Covenant's enforcement guidelines.
